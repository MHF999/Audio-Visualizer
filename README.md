### Technical Notes

The javax.sound.sampled API only supports 8-bit, 16-bit, and (on Unix) 24-bit PCM audio.
If you recieve an "Unsupported Bit Depth" error, then please convert your .wav file to an accepted format.
There are several free converters online, including the following: https://tinyurl.com/2z2nyadk and https://tinyurl.com/y9xt6pn6
